Final logo asset set for isotile (the pentagon patch a_patch with the pinwheel favicon a_patch_fav) generated by scripts/make_logo_assets.py, wired into the docs (header logo per color scheme, favicon, Branding page) and the README header on the docs-skeleton branch of PR 2. One logo shows in the header in each scheme; CI is green.

What changed

  • scripts/make_logo_assets.py (deterministic, no network) writes docs/assets/logo/: mark-light.svg, mark-dark.svg, mark-mono.svg, lockup-light.svg, lockup-dark.svg, favicon.svg, favicon-32.png, apple-touch-icon.png (180 px, white background) and social-preview.png. --check regenerates the SVG files in memory and fails if they differ from the stored files; the PNG files are not compared.
  • The mark is a_patch: seven tiles of type 28 around a four-valent vertex, one amber, six blue in three tints. favicon.svg and favicon-32.png use a_patch_fav (four tiles, gap 4.4). favicon.svg switches colors with prefers-color-scheme.
  • The name in the lockups and the tagline in the social preview are outlined paths of DejaVu Sans Bold and DejaVu Sans, so the files have no live text and need no font. DejaVu fonts (based on Bitstream Vera) allow embedding and redistribution; the font and license are recorded in docs/branding.md.
  • Docs: theme.logo, theme.favicon, custom_dir: docs/overrides with partials/logo.html (one <img> per scheme, classes it-logo--light and it-logo--dark), docs/stylesheets/logo.css ([data-md-color-scheme="default"] .md-logo .it-logo--dark and the slate counterpart set display: none; the selector includes .md-logo because Material sets display: block on .md-logo img), and the Branding page in the nav (usage, colors with contrast ratios, clear space, minimum sizes, do and do not, font and license, regeneration).
  • All SVG files carry explicit width and height, so they have an intrinsic size in the header and on the Branding page.
  • README header: a <picture> element with absolute raw.githubusercontent.com/bright-fakl/isotile/main/docs/assets/logo/ URLs for lockup-light.svg and lockup-dark.svg. They resolve after the merge to main; the render above uses relative paths.
  • CHANGELOG entry and a "Logo" section in the PR description.
