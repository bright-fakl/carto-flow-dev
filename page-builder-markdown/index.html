summary.md pages now support numbered lists, nested lists, fenced code blocks and bold. This page is its own example, so it shows the result.

What renders now

Before, a numbered list became one paragraph and **bold** showed as literal asterisks. The cases below are the ones that now render.

1. A numbered list with **bold** items. 2. A second item that continues on an indented line, with nested bullets:

  • first nested item
  • second nested item

3. A third item.

  • A bullet list.
  • A nested bullet.
  • A second bullet.

A fenced block is shown as written and is not parsed for lists or bold:

```python x = 1 < 2

  • not a list

**not bold** ```
