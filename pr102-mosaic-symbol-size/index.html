Mosaic symbols are now drawn at the tile's size for every tiling, so they no longer overlap; HexagonTiling output is unchanged. Left is main, right is the fix.

MosaicLayout set base_size to the tiling's tile_size, which is only the symbol size for HexagonTiling. It now uses Tiling.symbol_size_for_tile_size(tile_size), the inverse of tile_size_for_symbol_size. HexagonTiling output is bit-identical (max coordinate difference 0.0 in all three modes).
