## What changed

- `scripts/make_doc_figures.py` writes 26 SVG files (13 figures, `-light` and `-dark`) to `docs/assets/figures/`. It uses plain matplotlib (added to the `docs` dependency group only, `uv.lock` updated) and a script-local helper built on `cover`, tile polygons, `neighbors` and the type adjacency table; the library gains no plotting code.
- Dark mode: two variants per figure on a transparent background with the logo colors (light `#2c6e9e`, `#c27400`; dark `#85b7e0`, `#facc38`, plus a green and a plum for aspects and vertex-only neighbors), shown with Material's `#only-light` and `#only-dark` URL fragments.
- Output is deterministic: text as paths, fixed `svg.hashsalt`, date, creator, format and type metadata removed, path data rounded to 0.1 pt, collection styles moved to the group. Two runs in separate processes give identical files; `--check` compares with the stored files.
- Quickstart and adjacency figures run the Python blocks of the page up to the block that creates the object and draw that object, so they show what the code on the page produces.
- Pages: figures with alt text and a caption (`md_in_html`, `<figure>` and `<figcaption>`); short lead-in sentence in Concepts for the named families; a "Regenerate the figures" section in Development; CHANGELOG line.
- `tests/test_docs_examples.py`: every image of a page resolves and has alt text, and every figure file is shown on some page.

## Open questions

- The `named families` figure appears on Quickstart and on Concepts (same file). A separate drawing for one of them would be possible.
- CI does not run `make_doc_figures.py --check`; the files depend on the matplotlib version in `uv.lock`. It can be added to the docs workflow if wanted.
- The tint of the tiles is the type's coloring (three blue tints); on the hero figure IH84 shows only two tints.
